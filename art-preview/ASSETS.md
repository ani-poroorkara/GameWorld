# Style B preview assets

This directory is an isolated, runnable art and movement preview. Open `/art-preview/` through the local server. The preview does not access the game's browser storage. The main game now uses production copies of these approved PNGs under `assets/art/` through the shared `WorldArt` renderer; the original preview stays available for comparison. See [the production art guide](../docs/ART_GUIDE.md) and [the current sprite catalog](catalog.html).

## Artwork

Generated with the built-in image generation tool, using the middle B column of the approved comparison image as a style reference. Original PNGs are stored unchanged in `assets/`. The renderer reads the transparent bounds and individual animation cells at runtime; it does not substitute procedural shapes for these four subjects.

- `assets/traveler.png`: 3 columns × 4 rows; front, left, right, back. Each row: left step, idle, right step.
- `assets/dog.png`: same layout.
- `assets/cottage.png`: isolated cottage.
- `assets/oak.png`: isolated oak.

The ground, path, small flowers, fence, shadows, and petting effects are drawn by the preview code. This is a style study, not a completed replacement tileset. Animation sheets still need a manual cleanup pass before a full game rollout; generated frame proportions can vary slightly. This scene supports movement, path finding, companion following, depth sorting, basic obstacle collision, keyboard/touch controls, zoom, and petting. It contains no quests or combat.

## Generation prompts

### traveler

Use case: stylized-concept. Asset type: production 2D pixel art sprite for an actual browser RPG. Input image is STYLE REFERENCE ONLY. Match ONLY the MIDDLE column B 'Rich detail' of the reference, not A or C. Warm muted woodland greens, ochre highlights, earthy brown outlines, beautiful hand-placed-looking pixel clusters, 5-tone shading, crisp stair-stepped silhouette, no smooth digital painting or blur, consistent soft upper-left daylight. Transparent background, no checkerboard baked in, no labels, no text, no border, no ground plane. Create a character animation sprite sheet of the B brown-haired traveler wearing green scarf and tunic, brown leather belt with golden buckle, little tan backpack, dark brown trousers and boots. Make it charming, expressive, beautifully shaded and closely like B's enlarged traveler. CRITICAL layout: exactly 3 equal columns and 4 equal rows, canvas portrait aspect 3:4. 12 full-body sprites, one centered within each equal cell, fully separated by transparent padding, never touch cell boundaries. Every sprite occupies about 60% of cell width and 78% of cell height. Same character scale in ALL cells; feet on same relative baseline. Row 1 front facing toward viewer: left foot forward, standing idle, right foot forward. Row 2 left-facing profile: left foot forward, idle, right foot forward. Row 3 right-facing profile: left foot forward, idle, right foot forward. Row 4 back facing away from viewer showing backpack: left foot forward, idle, right foot forward. Orthographic three-quarter overhead RPG view, no isometric diamond. No weapons. Native pixel appearance about 48x64 pixels per character enlarged with nearest-neighbor to canvas resolution. Keep proportions nearly identical to center B reference.
