# Shipped Style B generation prompts

These assets were generated using the built-in image generation tool. The approved source sheets in `art-preview/assets/` were supplied as visual references; new files are stored under `assets/art/`. The original male traveler, dog, cottage and oak are copied unchanged from the approved preview; their original prompts remain in [the preview notes](../art-preview/ASSETS.md).

For image-generation work, read the imagegen skill and the [art guide](ART_GUIDE.md). New sources must pass the cell/bounds checks and be inspected at runtime, in context. Do not confuse a good isolated image with a completed integration.
